# InternTrack – Internship Management System

## a. Project Title & Description

**InternTrack – Internship Management System**

InternTrack is a web-based system designed to help students manage their internship applications, explore potential companies, and track their application progress in one place.

## b. Features Included

- **Dashboard** – View application statistics and recent applications.
- **Application Management** – Add, edit, delete, search and filter internship applications.
- **Company Directory** – Manage company information and records.
- **Internship Finder** – Discover recommended companies based on programme and location preferences.
- **User Profile** – Update personal and academic information and upload a profile picture.
- **Login & Registration** – Create an account and securely access the system.
- **Dark & Light Mode** – Switch between different display themes.

## d. Frameworks / Libraries Used

- **HTML5** – Structure of the website.
- **CSS3** – Website styling and layout.
- **JavaScript** – Functionality and interactive features.
- **Bootstrap 5.3.3** – Responsive layout and UI components.
- **Bootstrap Icons 1.11.3** – Interface icons.
- **Chart.js** – Dashboard data visualisation.
- **Google Fonts (DM Sans & Manrope)** – Typography.
- **LocalStorage** – Store user accounts, applications, company records, profile information and preferences locally in the browser.
